## 1. Perfume Terms

| Term | Definition |
|------|------------|
| Notes | Komponen aroma dalam parfum (top, middle, base notes) |
| Top Notes | Aroma pertama yang tercium (5-30 menit) |
| Middle Notes | Aroma utama (30 menit - 4 jam) |
| Base Notes | Aroma terakhir yang bertahan (4+ jam) |
| Sillage | Jejak aroma yang tertinggal |
| Projection | Seberapa jauh aroma tercium |
| Longevity | Ketahanan aroma pada kulit |
| Sillage | Jejak aroma saat bergerak |
| Dry-down | Perubahan aroma setelah diaplikasikan |
| Fragrance Family | Kelompok aroma (Floral, Woody, Oriental, dll) |

## 2. Perfume Concentrations

| Term | Concentration | Description |
|------|---------------|-------------|
| EDC | 2-5% | Eau de Cologne, ringan |
| EDT | 5-15% | Eau de Toilette, sehari-hari |
| EDP | 15-20% | Eau de Parfum, tahan lama |
| Parfum | 20-30% | Pure Parfum, paling konsentrasi |

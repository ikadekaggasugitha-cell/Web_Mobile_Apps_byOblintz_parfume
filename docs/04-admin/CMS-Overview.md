## 1. Overview

CMS (Content Management System) Admin Panel adalah backend management untuk mengelola seluruh aspek OBLINTZ platform.

---

## 2. Modules

| Module | Description |
|--------|-------------|
| Dashboard | Overview metrics dan analytics |
| Products | CRUD produk, inventory |
| Orders | Manajemen pesanan |
| Users | Manajemen pengguna |
| Reviews | Moderasi review |
| Content | Banner, artikel, FAQ |
| Marketing | Promo, campaign |
| Reports | Laporan dan analytics |
| Settings | Konfigurasi sistem |

---

## 3. Access

| URL | Description |
|-----|-------------|
| https://admin.oblintz.com | Production |
| https://admin-staging.oblintz.com | Staging |

## 4. Admin Roles

| Role | Access |
|------|--------|
| Super Admin | Full access |
| Admin | Products, Orders, Users |
| Content Manager | Content, Banner |
| Marketing | Promo, Campaign |
| Customer Service | Orders, Users |
| Finance | Reports, Refunds |

---

## 5. Dashboard Metrics

- Total Sales (Daily, Weekly, Monthly)
- Total Orders
- New Customers
- Top Products
- Recent Orders
- Stock Alerts
